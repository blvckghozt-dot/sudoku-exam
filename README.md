# เครื่องสร้างข้อสอบซูโดกุ

สร้างชุดปริศนาซูโดกุตามแบบฟอร์มการแข่งขัน (รอบที่ 1 ประถมศึกษา / รอบที่ 2 มัธยมศึกษาตอนต้น) พร้อมเฉลย บันทึกเป็น PDF และสั่งพิมพ์ได้

มี 3 แบบฟอร์ม: รอบที่ 1 (ประถม), รอบที่ 2 (ม.ต้น) และโหมดแข่งขัน EduPLOYS (ซูโดกุโปร) ซึ่งมีครบ 30 รูปแบบตามกติกา ได้แก่ Classic, Alphabet, Thai Alphabet, Diagonal, Jigsaw (6x6 / 8x8 / 9x9), Asterisk, Center Dot, Girandola, Even-Odd, Consecutive, Alphabet Diagonal, Alphabet Jigsaw, Diagonal Jigsaw, Windoku, Killer, XV, Rossini, GreaterThan และ Gattai Near 2 ทุกข้อตรวจแล้วว่ามีคำตอบเดียว ทุกหน้าใน PDF พิมพ์รหัสชุดไว้มุมล่าง เพื่อจับคู่ข้อสอบกับเฉลย
