# เครื่องสร้างข้อสอบซูโดกุ

สร้างชุดปริศนาซูโดกุตามแบบฟอร์มการแข่งขัน (รอบที่ 1 ประถมศึกษา / รอบที่ 2 มัธยมศึกษาตอนต้น) พร้อมเฉลย บันทึกเป็น PDF และสั่งพิมพ์ได้

รองรับ Classic, Alphabet, Thai Alphabet, Diagonal, Jigsaw, Even-Odd, Consecutive, Asterisk, Diagonal Jigsaw และ Windoku ขนาด 6x6 / 9x9 ทุกข้อตรวจแล้วว่ามีคำตอบเดียว

ใช้งาน: https://blvckghozt-dot.github.io/sudoku-exam/
